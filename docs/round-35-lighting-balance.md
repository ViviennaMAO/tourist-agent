# 第三十五轮：日光平衡与反射刷新

基线：611255b7。范围：tourist-agent / Explore，处理用户提出的光线光照问题。

## 调整

- 降低太阳、半球补光和环境贴图的叠加亮度，曝光从 0.97 调至 0.92；太阳保留暖色但减少偏黄，天空补光更冷。保持太阳方向不变，与水面和叶片透光方向一致。
- 加快天空由地平线向蓝色过渡，降低高楼额外空气透视的混合强度，保留远景层次并减少灰白覆盖。
- 两间滨水店铺的檐下局部反弹光提高，室内适度恢复环境补光、提高窗侧与吊灯附近的局部照明。补光仍随空间位置和进深衰减，是局部近似而非完整全局光照。
- 修复改变环境/精修设置或反弹光开关后，静态玻璃反射探针未重新采集的问题。

## 验证

语法检查、74 项测试、生产构建及 git diff --check 通过。测试中的着色器版本断言随缓存键升级到 v3，原行为检查保留。生产构建保留已有 Three.js 分块体积提示。

独立 Chromium / Metal、1440×900、DPR 1、环境定格 180 秒，检查滨水、花园、店铺、高楼、纵深、全景、哈利法塔底仰视七个机位。地标 54/54 加载，页面与控制台错误为 0。截图和运行记录见 validation/round-35。

额外操作验证：关闭再开启反弹光，反射采集计数 1→2→3；切换原始外观再恢复精修后，采集计数为 4，确认反射随光照刷新。原始外观下反射功能关闭，状态不显示计数。人物未定格，不使用人物位置评估静态光照差异。

## 限制

仍是实时栅格渲染，室内局部补光不会产生准确的多次反射。树冠中的烘焙暗色、程序化岸石和重复建筑细节仍影响写实程度；本轮没有将这些资产全部替换，也没有宣称达到参考图水平。未进行实体移动设备持续性能测试。
