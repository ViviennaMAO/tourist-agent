# 第十二轮：阴影边缘与幕墙修复

## 发现与处理
- 原 SSAO 的 5×5 等权模糊会跨越不同深度/法线的表面，扩大拱廊、叶片与窗框边缘的灰边。改为同尺寸、带深度和法线权重的滤波；继续保留 alpha 裁切、800 像素宽上限和近景范围。
- 静态反射的初次捕获原本发生在主渲染之前，可能采到上一相机或初始化时的太阳阴影贴图。捕获移到主渲染后，当前帧的阴影已完成，下一帧使用新反射；仍按失效刷新，不逐帧捕获。
- 高楼窗间深色横带由 0.22 缩窄为 0.14，改为独立的冷灰蓝材料并使用高楼反射探针，避免与传统商铺共用暗绿色玻璃。
- 高楼和后排楼群幕墙加入轻微的分片色差、粗糙度变化及玻璃曲面法线变化。远处按屏幕尺寸衰减，减少小窗格噪点。无新贴图、几何和依赖；独立窗间材料增加一个合批。
- 保持原材质回调调用链并传递 renderer，使幕墙细节与局部反射共存；销毁反射模块时恢复原回调。
