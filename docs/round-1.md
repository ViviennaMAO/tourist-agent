# 第 1 轮：独立 Explore 与材质基线

## 边界

用户指定目标仓库 `ViviennaMAO/tourist-agent`，新 Vercel 前端，仅 Explore。源项目及其部署不修改、不合并。本仓库从空历史开始，只复制授权范围内的游戏入口。

本轮保留十一城和现有玩法，拆除片头、建城播放、宣传片、视频/标志片尾及录制时间轴功能。建造脚本保留为城市几何生成数据，在 Explore 中直接求值到完工状态。

## 视觉处理

主脑将上一轮确定的“写实微缩城市”方向收敛为：固定广场机位、低饱和材质、石铺装尺度、自然环境光、清晰而克制的阴影。执行单元负责 Explore 提取，主脑负责材质模块和画面对比，之后依据实际截图修正草地重复纹理和评审面板布局。

本轮只增强迪拜的地面、基础材质与实例颜色；全局日光和环境反射作为统一基础。其他城市保持既有地表/模型。地标仍使用原模型及其贴图，不宣称恢复完整原始 PBR 通道。角色、棕榈叶、建筑立面和水面仍有风格化特征，留给后续局部精修。

程序化材质通过世界坐标投影，避免同一石板随几何体缩放变大。二维色彩图与高度图分别处理，粗糙度与微表面法线在同一坐标系计算。Before/After 切换可以恢复原材质引用、实例颜色和环境光，不更换相机或布局。

## 评审镜头

迪拜原点 (-345, 0, -230)，固定 seed `parallel-world`。

| 镜头 | 局部 camera | 局部 target |
|---|---|---|
| 全岛 | (105,105,130) | (0,3,-10) |
| 广场 | (27,22,-5) | (0,1.3,-32) |
| 近景 | (-7,6,-18) | (0,2,-33) |

固定镜头不自动弹出地标卡，环境定格在180秒；人物移动和切城后恢复常规玩法。评审模式通过 `?review=1` 打开，正常访客不显示开发指标。

## 已做验证

- JavaScript 语法检查和 Vite 生产构建通过。
- 初次桌面浏览器加载54/54地标，无加载失败或渲染错误。
- 从加载页进入游戏，城市导览、礼包关闭与固定广场机位可用。
- 近/远城市可见性、世界地图全显、拍摄远城时的可见性、帧时间上下界做了针对性断言。
- 桌面1440×900、DPR1、2048²阴影：固定广场快照326,673三角面、295 draw calls；抽样运行约97–120 FPS（同一台Mac浏览器，非硬件基准或移动端承诺）。优化前相同广场约757,221三角面、678 draw calls。
- 390×844窄屏检查：方向键显示、按住上键移动并触发哈利法塔打卡、地图十一城完整入画、Esc返回、菜单操作说明均通过。该检查是桌面浏览器窄屏验证，未测真实手机GPU。
- 城市按钮传送东京，地标卡、东京导览和城市印记正常更新；普通菜单不包含宣传片或建城动画入口。
- 三组同机位截图在 `docs/validation/`：全岛/广场为1440×900，近景为461×676 CSS像素（绘制缓冲691×1014，DPR1.5）；每组Before/After参数一致。窄屏探索与地图截图另存。所有图片均为真实游戏截图。
- 54/54地标成功，无加载失败；浏览器未记录渲染错误。依赖外部模型服务的长期可用性未作保证。
