# 第二十六轮：整体光线与高楼远近层次

日期：2026-11-03。基线 `4b26c52`。范围为 Tourist Agent Explore 的写实光照及迪拜高楼材质。

## 本轮调整

- 太阳强度由 3.55 降为 2.95，曝光由 0.97 降为 0.94；天空补光由 1.0 调至 1.32。太阳采用暖色、天空采用冷色，减轻亮面发白并保留暗部信息。沿用既有太阳方向与阴影接触处理。
- 高楼玻璃采用更低的蓝灰底色，粗糙度由 0.12 调为 0.18、反射强度由 1.35 调为 1.05，减少整面反光的苍白感；楼层遮挡板使用深灰蓝，金属框保留窄高光。玻璃逐窗色差仍随距离抗锯齿衰减。
- 30 栋后排建筑统一蓝灰、银灰及低饱和石材色，并在既有 5 个材质批次中加入薄楼层遮挡带，没有增加背景楼群绘制调用。
- 高楼空气透视改为较低亮度的蓝灰色，取消额外提亮，在距离 48–180 范围内逐渐降低对比；近处保持材质清晰。
- 高楼反射探针从 6.5 提高到 16，增加天空和上层立面的采样，减少地面占比。仍使用既有双探针近似反射。
- 没有调整建筑占地、道路、碰撞、人物或楼群排列。写实太阳、天空和曝光仍是原系统的全场景共享设置；材质改动限定在迪拜。
