# 迪拜东湾：摩天轮与邮轮码头

基线 6785134。仍仅在独立 tourist-agent 仓库开发，保留迪拜、阿布扎比、东京、拉斯维加斯四城。

## 场景与玩法

- 东侧海湾新建滨海广场和邮轮泊位，经两段接驳桥连接既有主岛；原跨城桥按新增岸线自动重算端点。新增岛块使用既有岸石与压顶精修。
- 滨海摩天轮：双层轮缘、拉索、A 形支架、轴心、24 个玻璃座舱、装载亭、长椅、灯具和花池。慢速旋转，座舱反向补偿，始终保持竖直；座舱通过实例绘制共享几何，总计 22,148 三角形、27 个绘制批次。
- 邮轮码头：候船厅、木色遮阳构件、沿岸栏杆、灯具、护舷、系缆柱、两条登船廊桥；泊位停靠带多层玻璃阳台、救生艇、船艏栏杆、舷窗和顶层泳池的邮轮。总计 20,460 三角形、34 个绘制批次。
- 两处加入迪拜地标目录、导览、点选、藏品直达及打卡。迪拜地标 6→8，四城合计 23→25。保留原地标资源加载路径，新增模型本地程序化生成，无新增外部模型下载。
- 新地标使用明确的岸上到达点与障碍物轮廓，避免整座轮盘半径把广场封死；行走表面与新铺装高度一致。移动附近游艇轨迹和 DUBAI 标志，避开新平台。
- 修复从验收定格视角通过藏品导航后仍保持定格、导致不触发打卡的问题。

## 验证

80 项测试、语法检查、生产构建与 git diff --check 通过。新增测试覆盖几何有限值与预算、资源只释放一次、座舱与实际实例矩阵在多相位下保持竖直、到达点在陆地和表面范围内且不落入障碍物。

独立 Chromium / Metal、1440×900、DPR 1，拍摄东湾、摩天轮、邮轮、原滨水街区、纵深和全景。地标 25/25 加载、页面及控制台错误为 0；反射设置刷新正常。通过实际藏品界面逐一点选两处新地标：两处到达坐标正确、打卡成功；从摩天轮到达点继续按键行走成功。最终脚底高度约为广场 1.08、码头 1.16 场景单位。截图与运行日志见 validation/dubai-harbor。

## 范围限制

这是风格化微缩场景，不是现实设施的测绘复刻。当前可在岸上广场、码头步行并打卡；未加入乘坐摩天轮、进入座舱、登船或航行玩法。邮轮停泊不航行，室内仅作外观展示。程序化花池、船体材质和部分构件仍可继续精修。构建保留原 Three.js 分块体积提示，未测试实体手机持续帧率。
