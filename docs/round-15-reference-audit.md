| 项目 | 本轮前的实际状态 | 本轮处理与剩余差距 |
| --- | --- | --- |
| 岸石 | 有压顶、粗糙材质和暗色底部，但仍是三排砖墙 | 改为 90 块不规则咬合石，独立深度、斜缝、破口、凹入灰缝；水线使用逐像素渐变。护岸有轻微凸凹，尚未重建参考图的大弧形岛岸。 |

| 树冠 | 已有新老叶、下垂、不同角度和透光 | 保留并随各树的高度、倾斜变化；不是独立制作的多个树冠资产。 |

| 光线 | 暖阳、天空补光已有，但偏均匀 | 降低太阳高度，调整方位；补光改偏冷、地面反弹减少黄绿，协调太阳强度与曝光。叶片和喷泉的近似日光方向同步。仍非离线全局光照。 |
| 铺装与街道 | 已去除重复纹理，压低接缝与大部分 AO 碎点 | 保留；细压顶边缘仍有屏幕空间阴影阶梯，需要后续针对性处理。 |
| 海水与喷泉 | 已有细波、动画水滴、分散落点涟漪 | 保留；海面仍用近似天空反射，缺乏参考图的丰富破碎倒影。 |

## 本轮验证

- 28 项测试通过，覆盖碰撞通道、A/B 恢复、资源释放、几何预算、岸石边界和垂花实际位置。
- 实景检查发现并修复岸石被原岸墙穿插遮挡；石面放在原岸墙外侧，未侵占玩家通道。
- 棕榈仍使用 3 个实例化绘制批次，每树小于 11,000 三角形；景观保持原有 170,000 三角形预算。
- 本地固定相机截图在 `validation/round-15/`。这是运行画面，不是生成参考图。
- 这轮补齐的是局部形状与光照，不能据此将清单标为全部达到参考图水平。
