# 石材、木材、船体与玻璃材质修复

基线 21ce46d；仅在独立 tourist-agent 仓库修改。

## 变化

- 港湾和摩天轮新增模型原先大量使用纯色 Standard 材质。本轮加入米制尺度的石材浅接缝、低对比色差、细孔隙、粗糙度变化和微法线；铺地单独使用较弱的颗粒层。按像素覆盖范围衰减细节，远处不显示高频噪点。近景复核后再次减弱孔隙凹凸，避免砂纸感。
- 较厚的石材构件增加 0.018 单位小倒角，保持碰撞包围不变。餐厅窗台和女儿墙改用石材，船体及摩天轮使用独立的低金属度漆面。
- 甲板、桌椅、木格架加入细微木纹与粗糙度变化；新增模型在静态合批前保留材质坐标，避免旋转不同泊位后纹理尺度或朝向跳变。既有滨水建筑木构也替换为经过距离过滤的纹理，遮阳棚增加近距离细织纹。
- 新增港湾静态反射探针，与既有庭院和高楼探针并存，店铺、船舶与座舱玻璃使用港湾环境。修正反射投影中实例矩阵的处理，保证移动座舱使用自身位置。高楼玻璃降低金属度和单块玻璃色差，保留幕墙轻微法线变化。

## 验证

85 项测试通过，语法检查、生产构建及 git diff --check 通过。新增测试验证材质回调组合、不同着色器缓存键、合批后材质坐标有限值与港湾反射绑定。保持原三角形/绘制批次预算：摩天轮 19,856 / 13，港湾 64,872 / 18（浏览器店招额外 20 三角形 / 10 批）。

独立 Chromium / Metal、1440×900、DPR 1，实际编译渲染全部新增着色器并复核餐厅、船舶、既有街区及高楼视角；25/25 地标加载，页面与控制台错误 0。指状码头、广场行走、藏品导航及打卡通过，照明切换后反射刷新正常。证据见 validation/dubai-materials。

当前仍使用实时程序化材质和静态环境探针，不是光线追踪或照片级资产。玻璃折射、完整室内及部分旧模型细部仍有限。新增一个探针只在需要更新时捕获，未验证实体手机持续帧率。
