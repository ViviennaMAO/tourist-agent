# 四城 Explore 版本

按用户要求，仅保留迪拜、阿布扎比、东京和拉斯维加斯。基线 8775038。

- 城市配置提取到 src/cities.js，仅包含四城配方与 23 个地标；另外七城从运行场景、地标加载、跨城桥梁及入口中移除，旧配方可从 Git 历史恢复。
- 保留四城的既有坐标、场景配方和地标定义，避免改变迪拜精修与镜头基准；剩余三条跨城连接构成连通路线。
- 标题、加载页、城市切换、导览、地标卡、门票、藏品、下一站和四城任务使用当前城市集合；城市编号为 1–4。
- 地图相机按当前四城边界取景，适配横屏和竖屏。
- 旧打卡记录保留在本地存储，但当前印记、等级和游历进度只统计有效的四城地标。旧历史订单保留，当前购票任务只统计保留城市的订单。访问旧城市链接回退到迪拜。
