# 圆岛、弧形港湾与日光喷泉

以 e0dd781 为基线，在独立 tourist-agent 中继续对照用户的迪拜广场参考图。

## 几何与通行

摩天轮平台改为半径 20 的圆形岛屿，铺装增加圆形底面，沿岸重新排列六间店铺。港湾改成向海围合的 120° 凹弧岸线，内外半径 32 / 39；四间餐厅朝向湾内。八艘船和五条指状码头沿岸线径向排列，保留独立水域间距。接驳桥、岸石、栏杆开口和到达点随新岸线调整。

岛屿边界、铺装、碰撞、到达点与码头行走表面共享布局数据。沿弧旋转的店铺保留包围盒用于场景布置，实际步行使用旋转后的建筑轮廓，避免将可通行拐角误判为障碍。圆岛外缘和港湾内缘保留连续步道。

## 光影与喷泉

- 日光方向调整为更高的斜射角，使用更暖的太阳光及偏冷天空补光。适度降低均匀补光和曝光、提高主光强度，让城市建筑不同朝向的明暗更明确。沿用实际投影、接触阴影、室内反弹光和玻璃反射；切换照明时重新捕获反射。
- 喷泉保留中央高柱与七道外弧，提高近景水束截面精度和透明水流可读性，增加独立落水飞溅。总计 560 个动态水滴，与环境定格保持同步。
- 水面扩展各落点的交叠涟漪，调整蓝绿色浅水与破碎高光；水面太阳方向与城市光照一致。
- 池壁大颗青色菱形替换为三排细密奶油色交叉花格及内凹暖灰底带，保留石材压顶和基座。
