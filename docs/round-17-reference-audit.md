# 第十七轮：植物层次、岸石尺度、石材倒角与局部反弹光

改动范围：Explore 迪拜滨水样板区；仅更新 tourist-agent，Eva 仍是多角度图片角色。

| 对照项 | 上一版差距 | 本轮修改 |
| --- | --- | --- |
| 植物丰富度 | 阔叶和粉色团簇重复，前排缺少细叶和白花层次 | 新增两处前排花池；混合细叶草、分枝白色五瓣小花和小叶地被；树池与后排花床也穿插细叶草和白花。两棵样板乔木补密叶簇。三角梅改用折叠尖苞片，减少圆片感。 |
| 石块尺度 | 90 块护岸石偏大，接缝像深色描线 | 改为 232 块，典型宽度低于 55 厘米、95% 低于 80 厘米；接缝内缩由 25 毫米降为 12 毫米，灰缝调浅，保留独立凸出、倒角、粗糙度与湿润水线。 |

| 间接光 | 拱廊暗部依赖统一环境补光 | 为两侧拱廊的石材、木饰和内墙增加局部暖色漫反射补光，随高度、距离和面朝向衰减，在 AO 和色调映射之前合成。验收页有独立“拱廊反弹光”开关。该项是有范围的实时近似，并非光线追踪或完整 GI。 |
