# 第八轮：高层建筑构造

本轮只修改迪拜街区精修中的背景办公塔楼。原先连续玻璃盒体改为三类轮廓：对称退台、石质边框、偏轴退台。沿用已有建筑高度上限，保留哈利法塔的主导比例；独立地标模型、传统建筑、Eva 图片角色与行走碰撞规则不变。

## 建筑细节
- 幕墙按真实几何分出竖梃、横档、楼层遮板和薄滴水边，少量暖色办公室打破完全重复的窗格。
- 退台设内收栏板和压顶；屋顶加入有间隙的百叶设备围护、顶盖与防水屋面。
- 底层是石柱、雨棚与退后 0.71 的玻璃门厅，配门框、竖梃和拉手。入口仅为外观，未添加可进入室内。
- 复用原有材质合批，不增加街区的 13 个材质批次上限；不新增外部贴图或模型请求。
- `?review=1` 中新增“高楼细节”相机；普通游戏无验收面板。

## 仍待精修
玻璃使用不透明环境反射近似，尚无真实室内、局部反射探针或透射。三种程序化建筑是微缩城市尺度下的风格化近似，距离参考图的摄影级材质和场景密度还有差距。
