# 第三十轮：实景复核、玻璃与日光

范围：tourist-agent / Explore。基线 b02bd0f。参考为用户提供的迪拜滨水街区图。

## 实际观察与修改

这轮恢复了独立 Chromium 的 WebGL 截图。先检查基线，再修改，再用相同机位复核；没有用参考图替代游戏画面。

- 基线高楼大面积玻璃呈均匀蓝板。调整为低饱和银蓝色，降低粗糙度、提高已有街区探针的反射贡献；近景能看到局部环境反光。加密楼层和窗格，细化竖框，保留阶梯、斜顶和石框式塔楼的区别。
- 背景楼群细化水平接缝和竖框。贴墙水平分隔改用朝外的单面几何，竖框保留厚度；全 30 栋候选生成时为 20,560 三角形、5 个批次，仍低于原有 30,000 三角形预算。没有增加楼栋数。
- 原海天交界有明显横向色带。天空地平线、场景雾和海面远雾共用颜色，并扩大天空过渡范围，最终全景中色带消除。太阳光强提高、半球补光略降，保留暖阳与冷天空补光；低层建筑的立体感仍需进一步改善。
- 滨水花境叶片横向铺开并略微抬高，减少中央一条叶带、两侧露土的形态。同一花床占地、碰撞与几何预算保持有效。近景仍可看出叶卡，尚未达到参考图的自然植被质量。

## 浏览器与回归验证

- Chromium Headless Shell / Metal，1440×900，DPR 1，环境动画定格 180 秒。截图直接来自游戏画布，没有修图。
- 最终复核滨水、全景、塔底仰视、花境近景、高楼五个机位：地标 54/54 加载；控制台、页面及游戏记录错误均为 0。
- 鼠标实际操作：进入塔底机位后点击“重置视角”，从 (900,680) 向上拖至 (900,500)。画面进入自由观察，塔尖出现在画面中，镜头仍高于地面。R 键恢复拖动前的位置与目标。之前的大幅拖动会越过塔尖看向天空，属于开放仰角下的正常结果。
- 这补充了第二十九轮仅有控制器事件测试的限制；未进行实体手机性能测试。验收面板的瞬时 FPS 不是持续性能基准。
- 69 项测试、语法检查、生产构建通过；Three.js 原有大分块提示仍存在。
- NPC 在环境定格时仍会随机走动，因此前后截图的人物位置不应作为静态差异判断依据。

## 图片与剩余差距

图片保存在 `validation/round-30/`：waterfront / panorama / skyline / promenade 的 before、after，以及 burjUp-after、mouse-up、reset-r；runtime.txt 记录最终机位状态。

仍需按参考继续推进：

1. 低层立面：改善石灰岩的尺度与柔和色差、墙角层次、室内纵深；目前墙面偏平整，窗型重复。
2. 植物：树冠目前仍有水平团块感，花境叶卡较硬；需要分枝结构、自然轮廓和更完整的灌木底层。
3. 护岸：当前块石仍过于拼贴整齐，需增加轮廓破碎、凹进缝隙与自然湿润接触带。
4. 全景：侧缘空铺装较大，前中后景布局仍偏模型网格；后续应优先做有目的的街区与种植组合，避免单纯堆加窗格和噪点。
5. 海面与喷泉：远处波纹仍重复，喷泉水柱偏细；需要减少规整条纹并加强落水扰动。

本轮是经实景复核的一次局部改进，并不宣称全城已达到参考图质量。
