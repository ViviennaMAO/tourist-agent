# 第三十六轮：树冠暗部与店内照明层次

基线：b7d1f146。范围为 tourist-agent / Explore，本轮保留既有全局曝光、太阳和天空配色。

## 修改

- 带照片贴图的叶片只提升原图暗部，保留较亮区域的原始颜色与叶脉对比。无贴图的棕榈叶保留顶点色，不应用照片暗部补偿。
- 乔木与精修棕榈共用薄叶补光：根据叶片世界法线计算有限的双面天空漫反射和透光近似，替换棕榈原先依赖观察方向的透光项。保留原透明裁切、投影和接收阴影；不提高全场曝光或使用自发光树叶。
- 两间滨水店铺以实际吊灯高度和三开间位置计算局部光照。按表面朝向和灯距衰减，让陶器、货架上表面和后墙获得不同明暗。
- 窗侧补光保持较冷，并随进深衰减；暖光集中在吊灯附近。第二轮截图后适度增强暖光，使灯下光感可见。
- 在已有三层货架的下沿加入窄范围柔和遮蔽，避免新增补光把货架与后墙照成一片。属于限定范围内的着色近似，不是精确光线追踪。
