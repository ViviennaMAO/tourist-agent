# 第二十二轮：岛上住宅尺度、空地花庭与双塔基座

日期：2026-11-03。基线 `d1f9481`。范围为 tourist-agent 的迪拜 Explore；保留 Eva 图片角色和原岛形。

## 完成内容

- 32 栋棕榈岛别墅从 1.25 单位高调整到 2.65，原 1.9 单位宽按地块约束扩到 3.0–3.8；深度仍为 1.5，避免狭长叶岛被建筑完全占满。沿岛轴小幅移位以避开棕榈根部，入口统一朝向侧边通路。
- 门与起居室窗分开处理，增加朝海背窗、侧窗、窗框、木檐和细女儿墙。窗台等细部最多超出主体约 0.05 单位。
- 在住宅之间生成 80 处低矮混合花庭，使用土层、米色细石边、深浅叶层、白花和少量粉花；门前增加小石板。花庭避让住宅和棕榈，6 个材质批次，不在通路上放高灌木。
- 放大的别墅和花庭增加与各自方向一致的碰撞范围。关闭精修或销毁模块时，移除自身范围，保留其他模块的数据。
- 阿联酋双塔独立底层平台收窄约 21%、缩短约 19%。底部约 0.94 单位高的台座压低至 0.282；3.3 以下裙房连续压低至 1.462。上方塔身整体下移，保持其自身形状与尺寸。原模型纹理和拾取层级保留，几何替换可恢复；没有把所有旧地标用同一比例缩小。

## 验收

- 50 项测试、语法检查及生产构建通过。既有 Three.js 分块超过 500 kB 的提示仍在。
- 复现全部 16 条源叶岛布局，验证 32 个新住宅地块仍在岸内、避开树根，入口朝向可通行侧。
- 按角色 0.45 单位净空，以 0.1 单位网格逐段搜索所有叶岛的连通侧路；放大住宅和花庭启用时仍连通。没有把此项代替全岛人工步行验收。
- 验证几何有限、共享材质与纹理不被销毁、反复开关不累积碰撞记录、平台高度映射连续且上部塔身不压扁。
- 本地浏览器：地标加载 54/54，运行错误 0，未捕获警告或错误。固定环境 180 秒、1280×720 CSS 视窗、DPR 1.5，检查岛上别墅与双塔平台。
