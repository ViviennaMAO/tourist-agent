# 第十三轮：护岸、树皮、花丛与石灰岩样板

- 喷泉前 x=-33…-7 的护岸改为三层不等宽粗砌石，独立浅色压顶；石块有轻微缺角、表面凹凸、矿物色差和深色水线。新增细节不改变导航面、岛屿边界和碰撞范围。其他岸线继续原样。
- 迪拜精修棕榈根部增粗并向上收细，保留原弯曲中心线、冠顶与地面连接；消除交替明暗的均匀环带，旧叶柄改为随机错位的扁菱形块面。实例方向和高度差继续保留，3 个合批不变。
- 花瓣由三角形改为五边圆片，随机大小、倾角；花池花簇的高度、侧向位置、屋顶花枝垂落长度打散。未增加新的挡路花池。
- 外墙使用独立石灰岩程序纹理：浅接缝、细孔、较弱板块色差和微表面法线；铺装继续使用原材质。略提环境补光、降低直射光强，保留太阳方向与暖色调。
- 验收界面增加“岸石细节”固定相机。保留 Eva 图片角色及原玩法。
