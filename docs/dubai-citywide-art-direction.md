## 全城统一的美术标准

- 色彩：暖灰米白石材、低饱和蓝灰玻璃、深棕木材、深色细金属件；植物允许深浅绿、少量枯黄、白花与粉花。材质差异通过表面结构和光照呈现。
- 比例：以角色、门洞、座椅和道路为共同尺度锚点。低层建筑厚墙深窗，高层建筑纤细竖向结构；构件粗细随体量协调。
- 光照：暖色斜射太阳、偏冷天空补光、适量地面暖反射。檐下能看见材质，受光墙面保留细节，灯具白天仅表现暖意。
- 细节：近景用轮廓、几何厚度和低对比纹理；中景保留建筑节奏；远景降低小窗格、接缝和反射的对比。允许不同建筑类型，共用材质尺度和光照规则。
- 自然变化：有组织地改变植物群落、石块、楼高和间距；避免纯随机噪点、等距排队或整城复制同一个样板。

## 后续优化清单

### P0：先解决全城观感与高楼

1. **空间层次**：明确滨水低层街区、过渡绿化与远景高楼的关系。修复裸露底板、硬边界和建筑基座与地面断开的感觉。保留游戏通路、地标交互及城市连接。
2. **楼群布局**：打散背景两排等距排列，形成高低不同、前后错落的组团与天际线空隙；为哈利法塔留出清楚的轮廓空间。不能仅靠增加楼数填满天空。
3. **高楼体型**：增加纤细直塔、局部退台、斜切冠部、转角玻璃与少量圆角楼体等家族；变化主次立面、基座、屋顶与设备遮挡。控制重复机房和层层缩进的积木感。
4. **高楼立面**：减轻粗黑窗框和深色腰带；区分玻璃、窗间墙与金属竖梃。反射随朝向与周围环境变化，减少整片重复云纹及突兀的棕色窗块。远景保留竖向节奏，避免密网格抢走前景注意力。
5. **远近空气感**：远楼逐步降低饱和度和对比度，偏蓝灰；近处仍保持清楚的石材与植物。与天空、海面雾色共同校准，避免统一灰蒙层。

主要入口：`realism.js`、`dubai-architecture.js`、`dubai-highrises.js`、`dubai-backdrop.js`、`dubai-landmarks.js`、`city-reflections.js`。

### P2：水体、地标及生活细节收尾

- 海水：大小波纹叠加、破碎高光、岸边反射与湿润接触带；降低规则连续条纹。
- 喷泉：透明感、落水扰动和细小水滴；池沿、装饰纹样与参考的细密石质效果协调。
- 地标：分别核对哈利法塔的细长分段、迪拜相框的厚度与细纹、未来博物馆的椭圆环体与开口；侧面、背面也应可读。其余迪拜地标保持识别特征并统一材质质量。
- 街具：细化桌椅腿、伞布褶皱、木座板、灯笼和花盆；核对人物尺度与接触阴影。
- 屋顶与背街：补足可见女儿墙内侧、屋顶收边、设备遮挡、后立面和巷道；避免主镜头之外恢复空白盒子。
- Eva：保留图片角色，检查方向切换、脚底贴地、人物尺寸及与环境的色温协调。

## 分轮验收办法

每轮只完成一组明确改动，并更新以下矩阵。未逐区域检查的项目保持“待验收”，不能因为使用同一材质或一个角度看起来更好而标为全城完成。

| 区域 | 本次审查状态 | 后续必查 |
| --- | --- | --- |
| 滨水样板 | 实景检查；仍有植物、立面和空间层次差距 | 正面、街道高度、侧后面、岸线连续性 |
| 西侧普通街区 | 实景检查；窗洞、木构和屋顶重复 | 路口、背街、屋顶、与样板交界 |
| 高楼与背景楼群 | 实景检查及代码检查；轮廓与布局重复 | 天际线、塔楼近景、侧向反射、落地基座 |
| 东侧街区与非样板海岸 | 全岛视角看到简化区域，未逐点近看 | 增补专用机位与步行检查 |
| 棕榈岛与桥头 | 全岛视角确认仍简化，未逐点近看 | 岸石、树干、低层建筑、桥路收口 |
| 地标背面与城市连接处 | 未完成逐点视觉验收 | 材质、几何背面、穿插与边界 |

验收步骤：

1. 固定同一时间、开关、相机及视窗尺寸保存修改前后图片；本次审查截图视窗有变化，只用于定性检查，不用于像素级评分。
2. 同时检查全岛、中景街区、地面步行三个尺度；新增东岸、棕榈岛、桥头与后街机位，覆盖当前预设未能验证的区域。
3. 将每栋建筑、岸段、树木群落、花池和街具映射到上述区域，登记所用几何／材质版本及验收状态，防止位置筛选留下旧资产。
4. 依次检查轮廓与比例、材质尺度、光线、接缝和植物落地，随后检查行走、碰撞和地标交互。
5. 对代表性桌面与移动视窗记录三角形、绘制调用与稳定运行表现；不能用一次瞬时 FPS 判断性能。远景使用合批和分级细节，避免无限加几何。
6. 修改涉及的测试与生产构建通过后，再验证线上效果。当前审查不代表以上待办已完成。
