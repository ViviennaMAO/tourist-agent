# 第二十五轮：屋顶装饰、旧桥梁与帆船外壳

日期：2026-11-03。基线 `567f2c8`。范围为 tourist-agent 的迪拜 Explore 及与迪拜直接相连的两座跨城桥。

## 完成内容

- 亚特兰蒂斯屋顶和上层檐口：从真实网格中提取水平边界，消除三角面内部对角线，增加细倒角压顶、金属滴水边和檐下齿饰。源模型识别出 252 条边、290 个齿饰位置。保留原有塔冠轮廓，将上部绿色金属饰面调为低饱和灰绿色。
- 屋顶精修和上一轮窗组共享石材、金属批次；亚特兰蒂斯整个附加组件共 54,444 三角形、6 个材质批次，没有增加屋顶单独绘制调用。
- 帆船酒店外壳：仅在中性饰面区域压缩旧贴图亮度，减弱烘焙灰色横带。保留蓝色玻璃、深色接缝及平台材质分区，继续由场景太阳、天空补光和动态阴影塑造体积；不是将整座酒店替换为无光照白材质。
- 两座岛内接驳桥：替换旧白桥身与桥墩，增加低对比石材步道、细金属立柱与竖杆护栏。保留源沥青、标线、道路端点及通行高度。
- 两座与迪拜直接相连的跨城桥：原 0.8 单位厚桥板改为 0.34 单位桥身；白色实心护栏改为开敞金属护栏，增加支承和石材铺装，并隐藏旧青色发光条。桥面高度与导航记录保持不变；其他跨城桥未修改。
- 桥面铺装使用带抗锯齿的低对比错缝和伸缩缝，避免大量小石板投射阴影造成碎点伪影。桥梁每座 5 个材质批次，开关恢复原组件，原共享材质和几何不被修改或销毁。
- 新增酒店屋顶、帆船外壳、跨城桥梁、酒店接驳桥四个验收机位。
